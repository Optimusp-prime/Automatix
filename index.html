Bienvenue dans Automatix¶

Comprendre les automates, les construire en Python et voir les mots prendre vie, symbole après symbole.

Automatix est un projet pédagogique réalisé dans le cadre d'un travail confié par M. Kagny François, mon professeur. Il relie les notions du cours de langages formels à des expériences concrètes : créer un automate, tester un mot, observer son exécution et comprendre le résultat.

La bibliothèque étend automata-lib 9.2.0 avec des outils pour les automates, les expressions régulières et les grammaires régulières. Vous pouvez commencer avec l'exemple ci-dessous, puis explorer les guides à votre rythme.

  • 1. ComprendreUn état décrit où l'on se trouve ; une transition indique où aller en lisant un symbole.
  • 2. ExpérimenterConstruisez un petit automate et comparez des mots acceptés et refusés.
  • 3. ObserverAnimez une exécution pour suivre chaque symbole et chaque transition.

Un automate, comment ça marche ?¶

Un automate lit un mot, c'est-à-dire une suite de symboles d'un alphabet. Il part d'un état initial et suit les transitions au fil de la lecture. Dans un automate déterministe, chaque symbole détermine au plus une transition depuis l'état courant.

Le mot est accepté si la lecture se termine dans un état final. Il est refusé si une transition nécessaire manque ou si l'état atteint après le dernier symbole n'est pas final.

Prenons un exemple simple : reconnaître a, aa, aaa, etc., mais refuser le mot vide. L'alphabet contient uniquement le symbole a.

Installer la bibliothèque¶

Avec Python 3.11 ou plus, ouvrez un terminal dans le dossier du projet :

python -m pip install -e .

Vous pouvez ensuite exécuter les exemples dans un script Python ou dans un notebook utilisant cet environnement.

Construire votre premier automate¶

from automata_extensions.fa import ExtendedDFA

dfa = ExtendedDFA(
    states={"q0", "q1"},
    input_symbols={"a"},
    transitions={
        "q0": {"a": "q1"},
        "q1": {"a": "q1"},
    },
    initial_state="q0",
    final_states={"q1"},
)

Au départ, on se trouve dans q0, qui n'est pas final. Le premier a mène à q1, un état final. Chaque a suivant nous laisse dans q1. L'automate reconnaît donc exactement les mots contenant au moins un a sur cet alphabet.

Tester et comprendre le résultat¶

print(dfa.accepts("a"))    # True
print(dfa.accepts("aaa"))  # True
print(dfa.accepts(""))     # False : aucun symbole n'a été lu

Pour aaa, le parcours est q0 → q1 → q1 → q1. Tous les symboles ont été lus et l'état d'arrivée est final : le mot est accepté. Pour le mot vide, noté ε en mathématiques et "" en Python, on reste dans q0 : le mot est refusé.

À vous de jouer : avant de lancer dfa.accepts("aa"), prédisez le résultat et retracez les états visités. Puis essayez le mot vide après avoir construit un nouvel automate où q0 est aussi final.

Voir l'exécution en vidéo¶

Dans la même session Python, vous pouvez exporter la lecture de aaa :

dfa.export_animation_video("aaa")

La vidéo est enregistrée dans animation.mp4, dans le dossier courant. Cet export nécessite Graphviz et FFmpeg : Automatix les cherche automatiquement dans le PATH, puis dans l'environnement Python courant. Le guide vidéo explique l'installation des outils, le choix du fichier de sortie et l'utilisation d'un autre environnement.
